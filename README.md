# DAA Assignment 3 — Graphs

Реализованы представление графа списками смежности, чтение из файла, DSU,
алгоритмы Краскала, Прима, Косарайю и Кана.

## Требования и запуск

JDK 25 (как настроено в pom.xml) и Maven 3.9+.
Команды выполняются из корня проекта:

```shell
mvn test
mvn package
java -cp target/classes org.example.Main data/connected.txt
java -cp target/classes org.example.Main data/cyclic.txt
java -cp target/classes org.example.Main data/dag.txt
```

В IntelliJ IDEA можно открыть Maven-проект, выбрать JDK 25 и запустить
`Main`. Без аргументов он читает `data/connected.txt`.

## Формат данных

```text
n m directed|undirected
u v w
```

После заголовка идут ровно `m` строк с рёбрами. Вершины: `0 .. n-1`,
веса: `int`, включая отрицательные. Пустые строки в конце допустимы.
Некорректные данные вызывают `IOException` с описанием причины.

Примеры: `connected.txt` — связный неориентированный граф,
`disconnected.txt` — несвязный граф с изолированной вершиной,
`cyclic.txt` — ориентированный граф с циклом, `dag.txt` — DAG с двумя источниками.

## Код

- `Graph`: единый тип для ориентированных и неориентированных графов.
- `Edge`: неизменяемое ребро `(from, to, weight)`.
- `GraphReader`: загрузка и проверка входного файла.
- `Main`: вывод графа и результатов обоих алгоритмов MST для неориентированного графа.
- `GraphTest`: JUnit 5 тесты графа, примеров и ошибочных файлов.
- `DSU`: система непересекающихся множеств со сжатием путей и объединением по размеру.
- `DSUTest`: проверка DSU, включая сравнение с простой эталонной реализацией.
- `Kruskal`, `Prim`: построение минимального остовного леса.
- `MstResult`: рёбра леса, суммарный вес типа `long`, число компонент и счётчики.
- `MstTest`: сравнение алгоритмов на 100 случайных связных графах,
  полный перебор на маленьких графах и проверка особых случаев.
- `Kosaraju`, `SccResult`: компоненты сильной связности и метрики DFS.
- `Kahn`, `TopologicalResult`: топологический порядок и обнаружение цикла.
- `DirectedGraphTest`: сравнение SCC с BFS, случайные DAG и цепочка из 100 000 вершин.

`edges()` содержит каждое добавленное ребро один раз. В списках смежности
неориентированное ребро хранится в обоих направлениях; петля имеет две записи.
Параллельные рёбра сохраняются. Возвращаемые списки доступны только для чтения.

`new DSU(n)` создаёт `n` отдельных множеств. `makeSet(n)` повторно инициализирует
структуру и обнуляет счётчики. `find(x)` возвращает представителя множества,
`union(x, y)` возвращает `true`, если множества были объединены,
а `components()` — текущее число множеств.

`findCalls()` считает вызовы `find`, включая вызовы внутри `union`.
`successfulUnions()` считает только успешные объединения.
`dsuOps()` возвращает сумму этих двух счётчиков. Некорректные аргументы
вызывают `IllegalArgumentException` без изменения структуры и счётчиков.

`Kruskal.compute(graph)` сортирует копию списка рёбер и использует DSU.
`Prim.compute(graph)` начинает с вершины 0, использует `PriorityQueue`
и продолжает с непосещённых вершин для остальных компонент.
Оба алгоритма возвращают лес для несвязного графа, учитывают изолированные
вершины и отклоняют ориентированный граф через `IllegalArgumentException`.
`Main` проверяет совпадение весов и числа компонент двух результатов.

Счётчик `edgeScans` у Краскала считает рёбра, проверенные после сортировки
до завершения дерева, а у Прима — просмотренные записи списков смежности
(две на каждое неориентированное ребро). `comparisons` считает сравнения
весов при сортировке или работе очереди. `dsuOps` у Прима равен нулю.
Счётчики независимы для каждого запуска.

`Kosaraju.compute(graph)` выполняет два итеративных DFS с явным стеком.
`componentOf().get(v)` возвращает номер компоненты вершины `v`.
`edgeScans` считает просмотр рёбер в двух DFS (ровно `2m`), не включая
построение обратного графа. `maxDepth` — максимальное число вершин в стеке
активного пути DFS за оба прохода.

`Kahn.compute(graph)` использует входящие степени, поддерживаемые `Graph`
при добавлении рёбер, и очередь. Для DAG `edgeScans` равен `m`.
При цикле `hasCycle()` равен `true`, а `order()` пуст: частичный порядок
не выдаётся за топологическую сортировку. Для циклического графа число
просмотренных рёбер может быть меньше `m`.
`Kahn.isValidOrder(graph, order)` проверяет перестановку всех вершин
и условие `pos[u] < pos[v]` для каждого ребра.
Оба алгоритма принимают только ориентированные графы. `Main` выводит
компоненты и топологический порядок либо сообщение о цикле.
